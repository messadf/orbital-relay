# Privacy

Orbital Relay does not collect, transmit, sell, or share personal information.

The extension listens only for failed top-level web navigations so it can open the locally packaged game after a connectivity-related failure. The failed address is passed to the local game page solely to display the hostname and power the **Retry connection** button. It is never stored or transmitted by Orbital Relay.

The game stores only the local high score and sound preference in browser storage. It contains no analytics, advertising, accounts, remote scripts, or network services.
