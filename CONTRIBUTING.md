# contribution

thanks for fixing the station. maybe, you wanna try your own game?

1. fork the repo and create a focused branch.
2. the main criteria is to keep the runtime dependency-free; that's all.
3. run `npm test`, `npm run check`, and `npm run build`.
4. make your alterations regarding the mechanics of the game.
5. create a pr.

in case of changing the logic, make sure you kept generated boards guaranteed-solvable; pls, don't add any telemetry or any other unwelcome software.
