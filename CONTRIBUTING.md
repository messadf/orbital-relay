# Contributing

Thanks for helping repair the station.

1. Fork the repository and create a focused branch.
2. Keep the runtime dependency-free and fully usable offline.
3. Run `npm test`, `npm run check`, and `npm run build`.
4. Test keyboard, pointer, and touch input when changing gameplay or layout.
5. Open a pull request explaining the player-visible change.

Please keep generated boards guaranteed-solvable and avoid adding telemetry or remote runtime assets.
